# 交付内容的归属与引用

同一信息只维护一份正文；其他阅读入口引用它。原型旁直接呈现适用规则是必要的上下文投影，从 spec 派生，不另写口径。

| 信息 | 正文归属 | 其他位置如何引用 |
| --- | --- | --- |
| 基本信息、背景依据、目标与指标索引、重要决策、做/不做、功能清单、既有能力影响 | PRD 第一章 | 原型与交付清单链接，不复写全局范围 |
| 角色与关键场景、业务实体与关系、模块流程和业务状态图 | PRD 第二章 | 功能详情仅列适用差异及上层/子图链接 |
| 功能入口、字段/内容表、行为、规则、异常恢复、待明确问题、边界用例、完整 GWT | PRD 第三章（spec） | 第六章、交付清单、原型链接到对应功能的验收折叠区并自动展开 |
| 成功指标计算口径 | PRD 第四章 | 第一章列指标与目标，第六章引用并安排效果验证，不复写公式 |
| 上线后效果验证计划 | PRD 第六章 | 实际观察结果进入复盘台账，未上线不预填收益结论 |
| 数据、非功能、发布条件、计划、风险、参考 | PRD 相应标准章节 | 功能/页面只补充局部差异 |
| 状态画面、必要元素和规则定位 | 页面原型 | PRD 按关联页面列一次，不重复各状态的同名控件清单 |
| 变更、确认/阻塞、分工、依赖、开发依据 | 交付管理 | 清单只组织交接和原文入口，不生成第二份 PRD |
| 实际执行结果、缺陷和复盘 | 验收记录与上线复盘 | 与验收条件区分；不能以文档确认代替执行结果 |

非原型详情正文使用可用内容宽度及正常边距，不为未使用的侧栏留空。

左侧以“需求文档（九章）→ 页面原型 → 补充资料 → 交付管理”组织。补充资料和交付管理默认折叠。已提供的章节不附重复状态字样；待补充和不适用仍显示。源文件入口与标准章节指向同一阅读页；保留历史版本和精确参数，不生成第二份正文。

不要机械删除有作用的相似信息：规则说明约束，边界用例说明代表性输入和预期，GWT 说明验收条件，图说明流转。保留各自新增的信息和追溯关系；规则全文不得在测试用例、交接清单、原型验收折叠区再次手写。长列表优先按功能/页面分组或折叠，不以隐藏替代缺项修复。控件的非空属性补充、状态独有元素、局部依赖和决策不能因去重丢失。

验证：九章与业务覆盖不减少；完整 PRD 的每条 GWT 正文仅出现一次；清单导出保留验收引用、历史版链接和分工依赖；原型当前规则可直接读；验收链接展开正确功能；切状态同步必要元素；对照仍覆盖全部状态。

## 减少重复而不减少交付信息

- 同一正常/边界/异常场景的前提、操作、预期在 GWT 维护一次；边界索引引用它。确有独立条件/数据/断言的用例才写补充，不能把空结果关联到接口失败等不同场景。
- 第五章引用第三章的业务一致性/权限/恢复规则和第四章的数据口径，只写新增质量目标、适用场景与验证方式；不可把相同要求再手写一份。
- 第六章已有验收入口、执行顺序和发布条件时，不再创建只有相同索引的测试菜单或同义上线清单。有独立测试数据、详细步骤、分工或执行证据再提供专门材料；实际结果仍进入台账。
- 生成依据、文字/画面表达理由留在质量报告；编辑器上传等操作帮助留在管理入口。业务阅读保留实际附件、必要画面入口、具体未决问题和确认状态。
- 同一控件面板不重复标题和定位清单；共用规则按需出现在多个控件旁是同源投影，不能为了去重让读者看不到当前必要约束。

## 面向下游的阅读取舍

交付审查分别走开发、测试、设计的实际任务路径，复用同一 PRD 和原型，不为三类角色复制正文或新增同义菜单。

| 角色 | 需要直接找到的信息 | 不宜作为主要阅读内容 |
| --- | --- | --- |
| 开发 | 适用范围、实体及关系、入口条件、判断与计算、操作副作用、结果与恢复、现有依赖 | 只有规则编号的跳转、生成过程、原始属性 JSON |
| 测试 | 可构造的前提与数据、操作、明确预期，正常/边界/异常及恢复，关联画面 | 只有 AC 编号的清单、把不同结果合并成“按系统处理” |
| 设计 | 各页面必要元素、真实控件及选项/默认、状态差异、提示文案、禁用原因、弹层触发与关闭/返回 | 将编辑工具画进业务界面、只写文字而缺少必要状态画面 |

规则与场景链接优先显示业务名称或场景前提/操作，编号保留作定位。共用规则尚未确认时，适用功能不得被整体“已确认”掩盖；仅供关联阅读的规则不自动视为继承约束。必要字段编码、精度、单位、时间口径及接口依赖仍须明确，不能以去技术化为由删除。

生成日志、覆盖检查明细、schema/selector、源路径和 Agent 指令放质量报告或修改上下文；正文保留业务需要的未决问题与真实限制。通用示例/验证说明集中说明一次，不在每章重复；局部未确认值仍在使用处标明。
