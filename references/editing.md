# 正式 PRD 编辑与变更影响

用户要求自行编辑 PRD 或用自然语言修订既有 PRD 时读取。此入口修改 Skill 生成项目的正式源内容；评审批注仍是独立意见。Skill 自身开发仅修改 Skill，验证使用临时项目。

## 本机编辑入口

纯自然语言小修订优先读 maintenance.md，使用精简查询/单条补丁，不先把 state 的全量 HTML 和文档输出给模型。需要跨字段修改包或可视化编辑时再使用本节完整编辑器。

```bash
python3 <skill>/scripts/edit_project.py <项目目录> --version v1.1
```

使用命令输出的完整本机链接打开编辑器。仅监听 127.0.0.1，随机端口、会话 token；服务只提供编辑页面与受保护的 API，不对外提供项目文件。关闭进程结束会话。当前文件锁实现支持 macOS/Linux；Windows 尚未验证，不宣称支持。静态分享站点无需编辑服务。

已支持：选择既有需求或 manifest 中登记的 Markdown；编辑需求标题、说明、规则、规则实例、Given/When/Then 验收，以及背景/测试/上线正文。先预览具体差异，再保存。来源、稳定 ID、规则关联、确认状态和项目结构不作为普通文本输入字段，避免随文案改动破坏关联。新增需求/规则、删除及改关联由 Agent 维护并验证。

## 原型属性编辑

在物料列表选择“原型 · 控件”，或点击布局预览中的控件。预览仅展示静态布局和属性草稿，不运行业务脚本；隐藏/禁用控件从列表选择，弹框内元素自动展开其弹框。属性写入 spec.interactions[].properties，不覆盖页面 HTML 内部结构。PRD 与本页需求面板展示同一份属性。

支持纯文字控件文案、占位提示、默认值、必填、文本最大长度、select 选项（每行 value=显示文字）、宽度 auto/compact/full，以及既有 navigate/dialog/close/toggle 的目标。含子元素的按钮不可整块改文案，防止破坏图标；请由 Agent 定位内部文字元素。没有覆盖属性时沿用 HTML 原值；“恢复此控件原始属性”清除属性覆盖，不改变跳转目标。目标恢复使用撤销或重新选择。

属性变更会把关联需求与规则标回 pending。结构化属性立即参与原型运行，但已有规则正文、提示文案、硬编码校验及依赖接口不会猜测性重写；根据影响报告复核这些位置。仅改属性不代表整个业务验收通过。修改默认值不等于覆盖持久化的用户数据，业务脚本仍可恢复实际状态。

属性编辑需要该规划版本已接入含 PS_PROPERTY_RUNTIME_V1 的共享 runtime；旧项目不静默升级，缺少支持时拒绝属性保存，先按用户范围升级规划版本再验证。冻结版本不升级。runtime 在页面业务脚本前应用白名单属性；页面脚本应读取原生约束/选项，避免再次用常量覆盖。动态创建元素和自定义状态逻辑仍由 Agent 处理。

保存后实际打开原型验证：文案/选项与默认值、边界输入、必填开关、目标页面/弹框、不同宽度、撤销后恢复及历史不变。编辑器布局预览不能替代这些验证。

编辑已有已确认规则或需求会标回 pending，保持原有来源信息并在保存记录中记录具体改动。保存不自动确认、冻结、发布或 checkpoint。历史 frozen/developing/released 只读。正文状态需在后续评审流程维护。

## 保存与冲突

1. 载入完整项目修订指纹，保留未知结构字段。
2. 预览稳定规则 ID 定位的前后差异及关联页面、控件、验收。正文缺少可验证的结构关联时，保守列出全部页面。
3. 保存前确认规划状态和指纹未变化，在临时副本构建/验证；验证失败不改原文件。
4. 验证后再次检查指纹；以独立临时文件替换变动源文件与构建产物，在项目 `.editing/` 保存备份和影响记录。
5. PRD 编译正文、站点数据、原型需求数据同步。声明式原型属性由 runtime 应用；自定义 HTML/JS 业务逻辑、独立测试正文和真实产品没有自动修改；影响列表必须作为后续复核任务，不得宣称全部同步完成。

多编辑服务的保存使用文件锁；外部编辑器不遵守该锁，仍应避免在保存期间同时运行构建或修改文件。指纹覆盖版本及站点文件，外部变更会拒绝旧草稿，不能强制覆盖。页面保留草稿，可导出后重新载入，由 Agent 合并。当前不提供自动合并及草稿导入界面。

“撤销上次保存”仅在项目仍匹配该次保存结果时有效。撤销也重新验证和编译，有后续改动则拒绝。浏览器刷新会失去会话内撤销按钮，但 `.editing/` 记录仍存在，可由 Agent 读取对应 ID 使用同一撤销入口；不要直接覆盖备份。

单文件替换是原子的，多文件不是数据库事务。普通写入异常尝试回滚；进程被强制终止可能留下 prepared 记录。遇到 prepared 时停止继续保存，读取其 backup_hex、影响报告和实际文件，说明恢复范围；按实际差异恢复或完成保存，再验证后标记该记录已处理。不得忽略记录重试或删除用户文件。备份可能包含完整 PRD，随项目管理，不作为公开站点资源。

## 自然语言修改与命令复用

从已有 HTML、需求/规则编号或控件定位自然语言变更时先读 incremental.md；revise_item.py 提供候选查询与稳定 ID 的单字段预览/保存。布局和自定义 JS 仍局部修改源文件，不重新生成页面。

先按 workflow.md 运行 impact、读取受影响源内容，再获取编辑状态：

```bash
python3 <skill>/scripts/edit_project.py <项目> --version v1.1 --action state
python3 <skill>/scripts/edit_project.py <项目> --version v1.1 --action preview --payload <修改包.json>
python3 <skill>/scripts/edit_project.py <项目> --version v1.1 --action save --payload <修改包.json>
python3 <skill>/scripts/edit_project.py <项目> --version v1.1 --action undo --payload <撤销包.json>
```

修改包为 state 返回的 revision、spec、documents，保留未改字段和所有已登记正文键；只改用户范围内内容。撤销包为 `{ "revision": "当前指纹", "undo_id": "保存返回的ID" }`。使用 apply_patch 写修改包。用户已授权修改时直接预览并保存，无需重复询问；真正存在无法判断的冲突才请求方向。命令不会调用模型，Agent 负责解释自然语言和业务规则。

保存后依据 report 逐项复核脚本、测试、旧值残留。project.py impact 也提供 rule_changes_since_checkpoint 的稳定 ID 前后差异，验收影响包含删除前的条目。完成相关修订及实际交互验证后再 checkpoint。只完成 PRD 编辑时，交付必须明确原型行为与测试仍待复核。
# 标准章节与文件附件

涉及完整 PRD、章节适用性或附录时先读 standard-prd.md。编辑器正文列表包含 prd.json 注册的 Markdown 来源；保存复用已有预览/冲突/撤销流程。文件附件在独立物料项上传，不能把文件名或浏览器临时 Blob 链接当成已保存附件。冻结正文只读，但可追加明确标识的项目级补充附件。
